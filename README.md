# 💻 nullSociety: The Iron Vault Exploit

Sebuah game **Terminal Simulator / Interactive Fiction** berbasis teks yang dioptimalkan untuk perangkat mobile (HP). Terinspirasi dari kisah thriller peretasan terkenal, game ini membawa Anda ke dalam kursi seorang peretas elit yang mengidap kecemasan sosial dalam misi meruntuhkan konglomerat terkorup di dunia.

## 🌟 Fitur Game
* **Retro Hacker UI:** Tampilan CLI (Command Line Interface) klasik dengan teks hijau neon yang responsif di layar HP.
* **Realistic Simulation:** Menggunakan perintah terminal semi-nyata seperti `nmap`, `python`, dan `rm -rf`.
* **Immersive Story:** Alur cerita spionase siber yang menegangkan dalam format obrolan teks dan eksekusi perintah terminal.

## 🕹️ Cara Bermain
1. Buka tautan GitHub Pages proyek ini di browser HP Anda.
2. Ketik `help` di terminal untuk melihat daftar perintah yang tersedia.
3. Ikuti instruksi dari rekan hacker Anda (**Darla**) melalui pesan teks terenkripsi yang muncul di layar.
4. Selesaikan semua misi sabotase siber tanpa terdeteksi oleh tim keamanan **V Corp**.

## 🛑 Disclaimer
Game ini murni fiksi interaktif untuk tujuan hiburan edukatif. Semua perintah, skrip, dan alamat IP dalam simulator ini adalah simulasi buatan dan tidak melakukan peretasan nyata apa pun di dunia nyata.
